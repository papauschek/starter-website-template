# Starter Website Template

A minimal, lightweight starter template for Scroll Works projects.

## Structure
- `index.html`: Main entry point
- `css/`: Stylesheets
- `js/`: Client-side scripts
- `assets/`: Images and media

## Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Scroll-Works/starter-website-template.git
   ```
2. Open `index.html` in any web browser.
3. For local development with live reload, use a simple server:
   ```bash
   # Using Python
   python3 -m http.server 8000
   ```
